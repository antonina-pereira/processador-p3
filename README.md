# Simulador do Processador P3
Projeto que pretende simular o processador P3 descrito em https://algos.inesc-id.pt/arq-comp/userfiles/downloads/manual.pdf.

## Tools Used
Node.js & npm
Node.js provides the JavaScript runtime used during development, and npm is the package manager that installs and manages all project dependencies. npm also runs the development and build scripts defined in package.json.

Vite
Vite is the development server and build tool for this project. The project uses a vite.config.ts file for configuration.

TypeScript
TypeScript adds static typing to JavaScript. Both .ts and .tsx files are supported, enabling typed logic and typed React components.

HTML & CSS
Standard HTML and CSS files form the structure and styling of the client‑side interface. These files are served and bundled by Vite.

Git
Git is used for version control, tracking changes to the project over time. A .gitignore file excludes build artifacts and dependencies such as dist/ and node_modules/.
